剧情由若干台词模块组成，每个模块 = 名字 + 挂载标识 + 播放方式 + 一组连续台词（每句可选说话人 小爱 / 阿伟 / 旁白，立绘直接在句上设置）。
挂载全自动：主线位（开场独白 / 回忆 / 变故 / 现实 / 通关）在固定节点播放；开战后N秒 / 击落第N架 / 血量降至N / Boss登场 在战斗中自动挂载；自定义标识由关卡页面调用 fireStoryMount('标识') 主动挂载。未添加的主线模块 = 该段跳过。
剧情统一保存在 Supabase plane_story 表（多设备同步，需登录后保存）；表未建或未登录时自动暂存浏览器缓存。保存后通过 level1.html?story=组名 触发。
