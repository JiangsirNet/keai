# ✈️ 爱的飞行员（plane）

> 原生 JavaScript 竖版飞机射击游戏，情侣主题改编版。

## 游戏简介

《爱的飞行员》是一款 HTML5 竖版飞行射击游戏。故事围绕飞行员「小爱」展开——多年训练空域中，伴飞搭档「阿伟」被外星飞行器用紫色牵引光束带走，小爱驾驶战机冲破外星残影敌机，循着残留的能量信号，跨越 10 片天空寻找他。

- 我方战机 1 架，敌机 7 种（e1~e7）+ 每关专属 Boss 母舰
- 我方 5 种子弹（默认/双枪/火焰/激光/散弹），敌方 6 种弹道
- 子弹具备攻速、攻击力、暴击率、暴击伤害属性
- 补给包系统：击毁特定敌机（穿梭机 e2、旋翼机 e7）随机掉落 8 种补给
- 10 大关卡：不同地点、不同敌机编队、Boss 强度逐关递进
- 第 1 关内置完整剧情（回忆 → 新手教学 → 突发变故 → 现实启程 → 通关线索）
- 俯视无缝背景 + 三层向下平滑滚动，移动端/桌面端均可玩

## 快速开始

```bash
cd plane-master
python -m http.server 8899
```

浏览器打开 `http://localhost:8899/index.html`。

- 支持移动端浏览器直接游玩
- 电脑端可按 F12 切换至移动端设备模式游玩
- 操作：按住/拖动战机移动，自动连续射击

| 编号 | 效果 |
|---|---|
| 0 | 子弹速度 +1 |
| 1 | 生命值 +1 |

## 第 1 关剧情《夜空：晚风初遇，骤然别离》

进入第 1 关自动播放，右上角可随时「跳过剧情」。

0. **开场**：小爱战机独自巡航在夜空中（自动飞行 1.5 秒）→ 独白「自那次事件以后，寻找阿伟的多少天，还是毫无进展。」
1. **回忆转场**：点击对话后画面变灰 → 变黑 → 浮现「回忆中」→ 恢复正常，两架战机（小爱白机 + 阿伟深蓝机）并肩飞行
2. **开场回忆**：星光夜空下并肩巡航，对话教学
3. **新手教学**：可操作阶段——移动战机、发射子弹、击碎气流碎片，阿伟侧后伴飞；完成三项任务自动推进
4. **突发变故**：紫色光团浮现 → 外星飞船锁定阿伟 → 牵引光束拖走战机 → 能量屏障挡住小爱 → 通讯断线「不要放弃……找到我……」
5. **剧情杀战斗**：阿伟被带走后，小爱战机满血出战 vs 外星飞船（巨型血条 50000，血厚不可战胜）。飞船发射追踪弹与直线弹幕；小爱血量耗尽后飞机**着火**（火焰+抖动），对话框显示痛苦喊叫「啊——！好烫……阿伟……我一定会……找到你的……」；约 3 秒后画面模糊 → **闪白** → 变清晰
6. **现实启程**：多年后小爱独自起飞，独白后正式开战
7. **通关剧情**：击败 Boss 后雷达捕捉到指向沙漠的微弱能量信号，解锁第 2 关

角色立绘（8 张透明 PNG）位于 `image/role/`：小爱（开心/坚定认真/感动流泪/担心焦虑）、阿伟（温柔微笑/坚定鼓励/感动含泪/担心牵挂）。

## 视觉与滚动

- 战机、敌机、Boss 为现代化 3D 渲染风格，全套原创素材（`image/` 目录）
- 10 张背景均为**俯视角**无缝衔接图，上下可完美首尾相连
- 背景采用**三层图层向下平滑滚动**（高度 960px），滚动回移无跳帧、无黑边
- 开始页为科幻城市夜空封面

## 评分系统

游戏分为 `SSS` / `AAA` / `BBB` / `CCC` / `DDD` 五个等级，依据得分结算；本地/局域玩法自动跳过云端入库，部署后可上报 Supabase 排行榜（`score.js`）。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（无框架、无外部依赖）
- 排行榜上报：Supabase（`https://fccsjbvkfllapyoozuvf.supabase.co`，表 `game_scores(game='plane')`）+ EmailJS 通知
- 本地服务：Python `http.server`
